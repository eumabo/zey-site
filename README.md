# ZEY — After Hours

Site em HTML, CSS e JavaScript com servidor local em Node.js.

## Rodar no computador

Abra o terminal dentro da pasta `zey-site-main` e execute:

```bash
npm install
npm run dev
```

Depois acesse:

```text
http://localhost:5173
```

Para parar o servidor, pressione `Ctrl + C` no terminal.

## Trocar a música

Substitua o arquivo `assets/music.mp3` por outro MP3 mantendo o mesmo nome.

## Trocar o nome da faixa

No `index.html`, altere o texto dentro de:

```html
<h2 id="trackTitle">TAKE CARE</h2>
```

## Trocar Discord

No `index.html`, altere `data-user="ghostenk"` e o texto `@ghostenk` do botão.
